# 系统图的画法：线型 · 聚焦 · 抽屉

backend-atlas 的 `viewer/graph.html` 怎么画、为什么这么画。改画法或给用户解释图时读；出图本身不需要。

画法跟着重点走：跨域直调 / 直连外部的线着警示色且总画；连共享域的线画淡（预期分层）。线型 = 关系种类（请求实线 · 写粗实线 · 读短虚线 · 推送圆点串 · 本机调用长虚线 · 出站点划线 · 调用虚线），颜色 = 色族（请求类蓝 · 推送类粉 · 写绿 · 出站橙 · 其余中性，取卡片色板）；聚焦的线上有点沿调用方向流动。浮岛「图例」按图上实际出现的种类列样本。聚焦只亮一跳，整条链路看业务循环；完全聚焦（点中卡 / 看循环 / 看体检项）时无关的线、起点、线上标签直接隐藏，只是悬停预览别的卡时才压暗。

**抽屉只认点击**：点卡 = 右缘主抽屉讲它；点主抽屉里一行 = 从那一行鼓出二级抽屉；二级里再点就地换成下一层、头部「‹」退回；再点同一张卡 / 同一行、×、点空白、Esc 收起。悬停一张卡 = 画布聚焦预览（只亮它那一跳，移开恢复），不弹抽屉。

**抽屉的排法**（图形扛信息，文字只做原子）：头 = 域色小块 + 面包屑 + 标题 + 路由；下面一排数（端点 / 循环 + 有入口占比小环 / 写到几张表；存储域换成 表 / 多域共写），只剩一个数时不画；再往下是分节列表，节与节之间只有小标题，行与行之间只有发丝线，整行是点击目标、右侧 › 表示往下一层。节：功能（色块 + 名字 + 一句 + 份量小条）→ 端点（动词 · 人话名 · 短路由 · 注释一句 · 入口数，无入口的整行压暗）/ 表（写入域色点 + 写入方）/ 文件 → 体检（前 3 条，其余折叠）→ 它依赖 / 依赖它（按域，小条 = 调用根数，命中体检着警示色）。循环视图 = 故事一句 → 从哪触发（前 5 处）→ 怎么走（竖脊串起编号步骤）。

**量大时**：展开框超过 16 项按平方根排成近方形；端点卡没有人话名时标题用方法名，路由去掉同组共同前缀。**抽屉按内容分节，不按归属**：表的分组写在语义层 `groups["D:pg"]`（账号 / 钱 / 剧本 / 任务…，漏一张 build 报错）；写入方只是每行右侧一列（build 从端点穿过共享 store 追到表，记在表节点 `writers` / `readers`：一个域写标域名，多个域写标「N 域写」，体检命中的着警示色）。端点按资源排，同一资源的读写挨着。过半表名共有的结尾词（…Entity）去掉。

没有客户端腿时（抽取为空）：头部标「无客户端」，循环不再逐条标「无入口」；有客户端时，无入口的循环收进折叠。
